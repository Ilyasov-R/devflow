# DevFlow

**DevFlow** — full-stack веб-приложение для управления проектами и задачами.

Приложение позволяет создавать проекты, управлять задачами, отслеживать их статус и организовывать рабочий процесс в одном пространстве.

> 🚧 **Проект находится в активной разработке.** Основной функционал уже реализован, сейчас ведётся дальнейшее развитие проекта.

---

## 📌 О проекте

DevFlow создаётся как современная система управления проектами, ориентированная на удобную работу с задачами и проектами.

Основная идея — объединить в одном приложении:

* управление проектами;
* управление задачами;
* статусы и приоритеты;
* визуализацию рабочего процесса;
* уведомления;
* авторизацию пользователей.

Проект разрабатывается с использованием **React + TypeScript** на frontend и **Node.js + Express + PostgreSQL** на backend.

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/DevFlow.git
cd DevFlow
```

### 2. Установка зависимостей frontend

```bash
cd client
npm install
```

### 3. Установка зависимостей backend

```bash
cd ../server
npm install
```

---

## ⚙️ Настройка переменных окружения

Для backend необходимо создать файл:

```text
server/.env
```

Пример:

```env
PORT=5000

DB_HOST=localhost
DB_PORT=5432
DB_NAME=devflow
DB_USER=postgres
DB_PASSWORD=your_password

JWT_SECRET=your_secret
```

> ⚠️ Файл `.env` не добавляется в Git и не публикуется в репозитории.

## 🗄 База данных

В качестве базы данных используется **PostgreSQL**.

Основные сущности:

```text
users
projects
tasks
```

Связь между сущностями:

```text
Пользователь
    │
    └── Проекты
          │
          └── Задачи
```

Каждый проект принадлежит пользователю, а задачи связаны с конкретным проектом.

## ▶️ Запуск проекта

### Backend

Откройте терминал:

```bash
cd server
npm run dev
```

### Frontend

В отдельном терминале:

```bash
cd client
npm run dev
```

После запуска frontend Vite покажет локальный адрес приложения.

Для проверки production-сборки frontend:

```bash

```

На текущем этапе проект успешно проходит TypeScript-проверку и production-сборку через Vite.
