# DevFlow

**DevFlow** — full-stack веб-приложение для управления проектами, задачами и командами.

Приложение позволяет создавать проекты, управлять задачами, работать в командах, приглашать участников и визуализировать рабочий процесс с помощью Kanban-доски.

> 🚧 **Проект находится в активной разработке.**
> Основной функционал уже реализован. Сейчас проект постепенно дорабатывается и готовится к production-версии.

---

## 📌 О проекте

DevFlow создаётся как современная система управления проектами и задачами.

Основная идея проекта — объединить в одном рабочем пространстве:

* управление проектами;
* управление задачами;
* команды;
* роли участников;
* приглашения в команды;
* статусы и приоритеты;
* Kanban-доску;
* Drag & Drop;
* авторизацию пользователей;
* Toast-уведомления.

Проект разработан с использованием **React + TypeScript** на frontend и **Node.js + Express + PostgreSQL** на backend.

## ⚙️ Переменные окружения

Для backend необходимо создать файл:

```text
server/.env
```

Пример:

```env
PORT=5000

DB_HOST=localhost
DB_PORT=5432
DB_NAME=devflow
DB_USER=postgres
DB_PASSWORD=your_password

JWT_SECRET=your_secret
```

> ⚠️ `.env` содержит конфиденциальные данные и не должен добавляться в Git.

## 🗄 База данных

В качестве базы данных используется **PostgreSQL**.

Основные сущности:

```text
users
projects
tasks
teams
team_members
team_invitations
```

Связи между сущностями:

```text
User
 │
 ├── Projects
 │     └── Tasks
 │
 └── Teams
       ├── Team Members
       └── Team Invitations
```

Каждый проект принадлежит пользователю, а задачи связаны с конкретным проектом.

Команда состоит из пользователей через таблицу `team_members`.

Приглашения пользователей хранятся в `team_invitations`.

## 🔒 Backend API

Для команд реализован REST API:

```text
GET    /teams
POST   /teams
GET    /teams/:teamId
PUT    /teams/:teamId
DELETE /teams/:teamId

POST   /teams/:teamId/members
PUT    /teams/:teamId/members/:userId
DELETE /teams/:teamId/members/:userId

POST   /teams/:teamId/invitations
```

Для работы с приглашениями:

```text
GET    /teams/invitations
POST   /teams/invitations/:invitationId/accept
POST   /teams/invitations/:invitationId/reject
```

Все защищённые endpoints используют JWT-аутентификацию.

Для команд дополнительно используются middleware:

```text
requireTeamMember
requireTeamRoles
```

Они проверяют членство пользователя в команде и его роль.
