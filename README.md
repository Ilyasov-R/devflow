# DevFlow

**DevFlow** — full-stack веб-приложение для управления проектами и задачами.

Приложение позволяет создавать проекты, управлять задачами, отслеживать их статус и приоритет, а также визуализировать рабочий процесс с помощью Kanban-доски.

> 🚧 **Проект находится в активной разработке.**
> Основной функционал уже реализован. В дальнейшем планируется расширение возможностей и подготовка production-версии.

---

## 📌 О проекте

DevFlow создаётся как современная система управления проектами и задачами.

Основная идея проекта — объединить в одном рабочем пространстве:

* управление проектами;
* управление задачами;
* статусы и приоритеты;
* Kanban-доску;
* Drag & Drop для изменения статуса задач;
* авторизацию пользователей;
* уведомления о результатах операций.

Проект разработан с использованием **React + TypeScript** на frontend и **Node.js + Express + PostgreSQL** на backend.

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/DevFlow.git
cd DevFlow
```

### 2. Установка frontend

```bash
cd client
npm install
```

### 3. Установка backend

```bash
cd ../server
npm install
```

---

## ⚙️ Переменные окружения

Для backend необходимо создать файл:

```text
server/.env
```

Пример:

```env
PORT=5000

DB_HOST=localhost
DB_PORT=5432
DB_NAME=devflow
DB_USER=postgres
DB_PASSWORD=your_password

JWT_SECRET=your_secret
```

> ⚠️ `.env` содержит конфиденциальные данные и не должен добавляться в Git.

## 🗄 База данных

В качестве базы данных используется **PostgreSQL**.

Основные сущности:

```text
users
projects
tasks
```

Связь между сущностями:

```text
User
 │
 └── Projects
       │
       └── Tasks
```

Каждый проект принадлежит пользователю, а каждая задача связана с конкретным проектом.

## ▶️ Запуск проекта

### Backend

Откройте отдельный терминал:

```bash
cd server
npm run dev
```

### Frontend

Во втором терминале:

```bash
cd client
npm run dev
```

После запуска Vite предоставит локальный адрес frontend-приложения.

---

## 🧪 Production Build

Для проверки production-сборки frontend:

```bash
cd client
npm run build
```

Команда выполняет TypeScript-проверку и собирает production-версию приложения через Vite.
